# Team5_PyLads_Python_Hackathon_May2026
Healthcare analytics and Python hackathon by Team PyLads

**Description about the dataset** 

This project uses the HUPA-UCM Diabetes Dataset, a multimodal healthcare dataset containing real-world data collected from patients with Type 1 Diabetes using CGM devices, insulin pumps, and wearable fitness trackers.

The dataset includes:

Glucose readings
Insulin dosage
Carbohydrate intake
Heart rate
Physical activity (steps/calories)
Sleep metrics
Patient demographics

The project focuses on data preprocessing, descriptive analysis, and prescriptive insights to understand how lifestyle and physiological factors influence glucose behavior and diabetes management.

**Source**: Mendeley Data Repository

**Problem statement**

Diabetes patients often experience fluctuations in glucose and heart rate levels, which can increase the risk of complications such as hypoglycemia, hyperglycemia, and cardiovascular issues. Monitoring these biomarkers manually across large datasets is difficult and time-consuming for healthcare professionals.

This project aims to develop an interactive Diabetes & Cardiovascular Analytics Dashboard using Python to analyze glucose and heart rate data through descriptive, predictive, and prescriptive analytics. The dashboard helps identify abnormal patterns, patient risk levels, glucose variability, and health trends to support better clinical decision-making and patient monitoring.

**Methods and Analysis**

**Methods Used**
Data cleaning and preprocessing
Handling missing values and duplicates
Data merging and transformation
Exploratory Data Analysis (EDA)
Correlation analysis and visualization

**Analysis Performed**
Glucose trend and variability analysis
Biomarker correlation analysis
Demographic-based analysis
Prescriptive insights for diabetes management

**Tools**
Python, Pandas, NumPy, Matplotlib, Seaborn

**Key Findings**

Glucose levels showed noticeable variability across patients and demographic groups.
Higher carbohydrate intake was associated with elevated glucose levels.
Heart rate and physical activity demonstrated measurable relationships with glucose fluctuations.
Patients with lower activity levels tended to exhibit greater glucose variability.
Correlation analysis highlighted meaningful interactions between glucose, insulin dosage, lifestyle factors, and physiological biomarkers.
The analysis supports the importance of personalized diabetes management strategies based on behavioral and physiological patterns.
